# Referencias de estudio — Machine Learning

Las referencias son puntos de entrada, no una lista exhaustiva ni una lectura obligatoria en orden. Prefiere textos primarios, documentación oficial, cursos universitarios y materiales que declaren sus supuestos. Para herramientas o modelos cambiantes, verifica la versión vigente antes de depender de detalles concretos.

- **[scikit-learn — User Guide](https://scikit-learn.org/stable/user_guide.html):** Referencia práctica y conceptual para algoritmos, selección de modelos, métricas y evaluación.
- **[Google — Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course):** Material introductorio sobre conceptos de ML, datos, métricas y modelos.
- **[An Introduction to Statistical Learning](https://www.statlearning.com/):** Texto accesible para fundamentos estadísticos, regresión, clasificación y métodos clásicos.
- **[The Elements of Statistical Learning](https://hastie.su.domains/ElemStatLearn/):** Referencia más matemática para comprender métodos y supuestos.

## Criterios para evaluar una fuente

- ¿Es material primario, documentación oficial, libro de referencia o interpretación secundaria?
- ¿Qué versión, conjunto de datos y condiciones respalda la afirmación?
- ¿Qué parte es resultado medido y qué parte es opinión o hipótesis?
- ¿Hay límites, datos de evaluación, comparaciones justas y resultados negativos?
- ¿Qué afirmación concreta queremos comprobar al consultar la fuente?
